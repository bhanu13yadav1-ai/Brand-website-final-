BLACKED VISUAL DEMO — UPDATE PACKAGE

What is included
- index.html: updated responsive demo based on Brand-website-3's concept.
- design-previews/: all 7 generated BLACKED UI mockup collages.
- The homepage now includes a visual-direction preview and hamburger-menu access to a zoomable gallery.
- The visual boards are kept separate from product photos so a whole UI screenshot is not mistaken for a product image.

How to apply from Android/GitHub
1. Keep a backup/download of the current repository first.
2. Extract this ZIP.
3. Upload/replace index.html at the root of the existing Brand-website-3 repository.
4. Upload the entire design-previews folder, preserving its folder name.
5. Do NOT delete the repository's existing product images, 360-demo frames, SVGs, CSS/JS or other files. The demo still references those existing public files.
6. Commit the changes and wait for GitHub Pages to publish. Refresh/open the Pages URL again on your phone after publishing.

What is and is not live
- Local demo interactions include browse views, demo cart, wishlist, product detail, comfort quiz and local photo preview.
- No real login/database, inventory, shipping, payment or order placement is connected.
- Product photos, prices and UI-board labels are concept/demo content; verify rights and product details before commercial use.
- The connected GitHub access used to prepare this package is read-only, so the repository was not changed or published automatically.
